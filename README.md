# 📈 Signal Processing & Time-Frequency Analysis Learning Notes

本仓库记录了信号处理与时频分析（Time-Frequency Analysis）的学习笔记与 Python 代码实战。

## 📚 目录与学习进度

- **Day 1: 连续信号与离散采样**（`day1.py`）
  - 用密集采样点近似连续信号，对比连续波形与 Fs = 20 Hz 的离散采样点（茎图）。
- **Day 2: 采样定理与混叠 (Aliasing)**（`day2.py`）
  - 9 Hz 信号以 10 Hz 采样时混叠为 1 Hz 假信号的实验，验证奈奎斯特采样定理。
- **Day 3: 傅里叶级数合成方波**（`day3.py`）
  - 逐步叠加奇次谐波（幅值 4/(nπ)）合成方波，观察吉布斯现象。
- **Day 4: 用正交性求傅里叶系数**（`day4.py`）
  - 手动用正交性数值积分求方波的 b_n 系数，并与理论值 4/(nπ) 对照。
- **Day 5: 奇偶对称性与傅里叶系数**（`day5.py`）
  - 对比奇方波（只有 sin 分量）与偶方波（只有 cos 分量）的系数分布。
- **Day 6: FFT 与单边频谱**（`day6.py`）
  - 对混合信号（50 + 120 + 300 Hz）做 FFT，归一化并取单边频谱读出各分量幅值。
- **Day 7: 频率分辨率与补零 (Zero-Padding)**（`day7.py`）
  - 对比短采样、补零与长采样：补零只让曲线平滑，不增加真实分辨率（Δf = 1/T）。
- **Day 8: 加窗与频谱泄漏**（`day8.py`）
  - 非整数周期信号（50.3 Hz）的泄漏现象，汉宁窗抑制泄漏及 sum(win) 归一化。
- **Day 9: 频域滤波与 iFFT 重构**（`day9.py`）
  - FFT → 频域低通掩码 → iFFT，从带噪信号中重构出 10 Hz 有用信号。
- **Day 10: 短时傅里叶变换 (STFT) 基础**（`day10.py`）
  - 使用 `scipy.signal.stft` 计算与绘制二维时频谱图。
  - 理解 `nperseg`（窗口长度）对时频分析的基本影响。
- **Day 11: 海森堡测不准原理与窗口长度权衡**（`day11.py`）
  - 探究信号处理中的时频分辨率博弈（$\Delta t \cdot \Delta f \ge C$）。
  - 长窗口（高频分、低时分）与短窗口（高时分、低频分）的对比实战。
  - 拓展：小波变换（CWT / PyWavelets）如何通过自适应动态窗口打破固定窗口限制。
- **Day 12: 重叠率 (Overlap) 与 Hop Size 的工程权衡**（计划中，代码待补）
  - 理解 `Hop Size` 与 `noverlap` 对时间轴采样密度的影响。
  - 加窗边缘效应补偿与时频谱平滑度分析。
  - 50% ~ 87.5% 重叠率的工程选型与计算量权衡。

另有 `fft.py`：早期练习，用 `rfft` 计算单边频谱的简化版。
